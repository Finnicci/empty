# Bloomhaven Art Bible

## 1. Visual Identity

Bloomhaven is a cozy, modern pixel-art flower farming and florist business game.

The visual identity should communicate:

- Cozy
- Discovery
- Living nature
- Flat readability
- Flowers as the visual heroes

## 2. Core Art Pillars

### Pillar 1: Cozy

Warm, welcoming, soft, relaxed.

### Pillar 2: Discovery

The world should suggest hidden flowers, journal pages, rare insects, and secrets.

### Pillar 3: Living Nature

Grass, flowers, clouds, bees, butterflies, and water should make the world feel alive.

### Pillar 4: Flat Readability

Assets should be easy to understand instantly, especially on mobile screens.

Use:

- Strong silhouettes
- Limited texture noise
- Simple value structure
- Clear color separation
- Bold shapes

Avoid:

- Overly detailed rendering
- Heavy gradients
- Cluttered backgrounds
- Tiny unreadable details

### Pillar 5: Flowers Are the Heroes

Flowers should receive the most visual attention.

## 3. Style Rules

Use:

- Modern cozy pixel-art inspiration
- Flat illustration influence
- Rounded forms
- Soft contrast
- Botanical journal textures
- Paper, wood, garden, and flower motifs

Avoid:

- Glossy mobile-game UI
- Aggressive colors
- Dark fantasy styling
- Hyper-realistic rendering
- Excessive particle effects

## 4. Tone

Bloomhaven is:

- 80% grounded
- 20% magical

Magic should feel rare, delicate, and special.

## 5. District Visual Identity

All districts share the same overall art style.

Districts may have different visual identities, but not completely different art styles.

Shared across all districts:

- Same tile scale
- Same UI language
- Same character proportions
- Same flat readability rules
- Same cozy pixel-art foundation

District differences should come from:

- Palette
- Flora
- Architecture
- Weather
- Mood
- Magical influence

## 6. District 1: Bloomhaven Town Square

Theme:
Restoration

Mood:
Warm, familiar, hopeful, neglected but recoverable

Palette:
Cream, warm green, lavender, soft yellow, sky blue

Flowers:
Daisy, Tulip, Lavender, Marigold, Rose

Architecture:
Cottage, wood storefronts, planter boxes, garden fences

Magic level:
5%

## 7. UI Standards

UI should feel like:

- Grandfather's gardening notebook
- A florist ledger
- A cozy field journal

Use:

- Cream paper cards
- Soft green accents
- Warm wood tones
- Botanical dividers
- Rounded buttons
- Clear quality badges
- Large tap targets

Avoid:

- Clutter
- Tiny icons
- Neon colors
- Excessive shadows
- Red notification spam

## 8. Flower Card Standard

Flower cards should prioritize the flower illustration.

Each card should clearly show:

- Flower name
- Rarity
- Quality when relevant
- Traits
- Value

## 9. Animation Standard

Animate gently:

- Grass sway
- Flower sway
- Butterfly flutter
- Bee movement
- Cloud drift
- Day/evening/night atmosphere

Avoid over-animating UI.

## 10. Screenshot Test

Every screen should answer yes to:

- Does this feel cozy?
- Are flowers visually important?
- Is the UI readable on mobile?
- Does the screen suggest discovery?
- Does it still feel like Bloomhaven?
