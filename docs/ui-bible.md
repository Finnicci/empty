# Bloomhaven UI Bible v1.0

## Buttons, Typography, Panels, Icons & Interactive Elements

The Bloomhaven UI should feel like an extension of the world, not an overlay placed on top of it.

Every button, icon, panel, and piece of text should look like it belongs inside a handcrafted botanical journal or an old florist's workshop.

The UI should reinforce Bloomhaven's core identity:

- Cozy
- Botanical
- Handcrafted
- Calm
- Discoverable
- Readable
- Timeless

Never design UI that resembles a generic mobile game.

## Core Design Philosophy

### The UI should disappear.

Players should notice:

- Flowers
- Farm
- Character

before they notice the interface.

The interface should gently support the experience.

## Visual Language

Bloomhaven's UI combines four inspirations:

### Botanical Journal

- Cream paper
- Pressed flowers
- Handwritten notes
- Sketches

### Florist Ledger

- Wood
- Labels
- Plant tags
- Wax seals

### Stained Glass

Reserved only for:

- Achievements
- Discovery moments
- Collection progress
- District emblems

Never use stained glass for standard buttons.

### Cottage Workshop

- Warm wood
- Rounded edges
- Brass hardware
- Natural materials

## Color Palette

### Primary

- Cream Paper: `#F5EFD8`
- Warm White: `#FFF8EA`
- Soft Sage: `#B9D3A3`
- Garden Green: `#6E8B5D`
- Rich Brown: `#7A5637`

### Accent Colors

- Peony Pink
- Lavender Purple
- Sunflower Gold
- Robin Egg Blue
- Wildflower Violet
- Rose Red

These should appear sparingly. Flowers provide the strongest colors.

## Typography

### Font Personality

Friendly. Readable. Storybook.

Never corporate. Never futuristic.

### Hierarchy

#### Title

Large, rounded, elegant, slightly whimsical.

Example: Bloomhaven

#### Section Headers

Bold, simple, comfortable spacing.

Examples:

- Plant Flowers
- Florist
- Journal
- Hybrid Garden

#### Body Text

Highly readable.

Avoid thin fonts. Avoid compressed fonts. Comfort over style.

#### Numbers

Large enough to read instantly.

Coins, Energy, Pollination, and Reputation should never require effort to read.

## Button Bible

### Philosophy

Buttons should feel touchable, like polished wood, not digital rectangles.

### Shape

- Rounded rectangle
- Large tap area
- Comfortable padding
- Never razor-sharp corners

### Material

- Light wood
- Painted wood
- Pressed paper label
- Botanical tag

### Default Button

- Warm cream
- Brown border
- Soft shadow
- Dark text

Hover:

- Slight lift
- Slight brighten

Click:

- Compress slightly
- Gentle bounce

### Primary Button

Examples:

- Plant
- Harvest
- Continue

Use golden cream, slight warmth, and the highest contrast.

### Secondary Button

Examples:

- Journal
- Settings
- Valley

Secondary buttons should be more muted.

### Disabled Button

- Desaturated
- Paper gray
- Still readable
- Never invisible

### Dangerous Button

Very rare.

Use muted berry red. Never bright red.

## Icon Bible

Icons should feel hand-designed, not system icons.

### Style

- Flat
- Simple
- Bold silhouette
- Rounded
- Minimal detail

### Examples

Coins: small flower coin, not gold disks.

Energy: leaf.

Pollination: bee.

Research: journal.

Reputation: blooming flower badge.

Hybridization: two crossing stems.

## Panel Bible

Panels should resemble:

- Old paper
- Notebook pages
- Plant labels
- Wood frames

### Background

- Cream paper
- Subtle texture
- Soft gradients only

### Border

- Rounded
- Warm brown
- Thin
- Never black

### Corners

Soft, comfortable, friendly.

## Notification Cards

Use:

- Cream paper
- Botanical illustration
- Small flower icon
- Minimal animation

Never use:

- Red banners
- Pop-up advertisements
- Large flashing alerts

## Discovery Window

This is the most important UI element.

When discovering a flower:

Background:

- Soft cream
- Stained-glass border

Flower illustration should occupy 70%.

Display:

- Flower Name
- Scientific Name
- Traits
- Native Region
- Interesting Fact
- Grandfather's Note

The player should pause to admire the flower.

## Journal Pages

Should resemble real botanical journals.

Include:

- Flower illustration
- Pressed petals
- Handwritten notes
- Sketches
- Soil information
- Native map
- Bloom period
- Small stained-glass collection badge

## Inventory Cards

- Large flower illustration
- Quality ribbon
- Name
- Quantity
- Traits
- Simple, no clutter

## Shop Cards

Look like florist order slips.

Include:

- Customer
- Requested flowers
- Reward
- Deadline
- Wax seal
- Handwritten notes

## Animation Standards

Every interaction should feel gentle.

Buttons:

- Lift
- Compress
- Bounce slightly

Cards:

- Fade
- Slide
- Paper turn

Flowers:

- Bloom
- Sway
- Petal flutter

Icons:

- Tiny bounce
- Soft fade

Never:

- Shake violently
- Flash
- Pulse rapidly
- Explode

## Sound Pairing

Every UI interaction should imply:

- Paper
- Wood
- Leaves
- Glass
- Nature

Examples:

- Page turns
- Wood taps
- Bee hum
- Soft chime
- Birdsong

Never use arcade beeps.

## Accessibility

- Minimum tap size: `48x48px`
- High contrast text
- Clear hierarchy
- Color never communicates information alone
- Always pair color with icons or labels

## The Bloomhaven Test

Every new UI element must pass these questions:

1. Would this feel natural inside a flower shop?
2. Would Grandfather have used something like this?
3. Does it compete with the flowers?
4. Can it be understood in under one second?
5. Does it make the world feel warmer?
6. Does it encourage calm rather than urgency?

If the answer to any question is "no," redesign the element.

## Final Rule

The player should remember Bloomhaven's flowers, farm, and discoveries, not its buttons.

Great UI should quietly support the experience while making the world itself the true focus.
